# 알려진 이슈

## PDF 미리보기 렌더링 차이

상태: 확인됨

확인일: 2026-05-27

영향 범위:

- 공보/5대공약 PDF 미리보기 화면
- 일부 선관위 PDF 중 투명도, 마스크, CMYK 이미지 레이어를 많이 쓰는 파일

대표 사례:

- 후보자: 추미애
- 후보자 ID: `100163148`
- 선거: 경기도지사선거
- 문서: 선거공보
- 원본 PDF: `https://cdn.nec.go.kr/policy_pdf/20260603/PDF/PBINFO/4100/003_100163148_20260525_2.pdf`

증상:

- 다운로드 후 네이티브 PDF 뷰어로 보면 후보자 이름이 정상 표시된다.
- 앱 내부 미리보기에서는 후보자 이름 영역이 검은 박스처럼 보이거나 흐릿한 검은 그림자로 표시될 수 있다.
- 모바일 Chrome, 데스크톱 Chrome, 인앱브라우저의 렌더 결과가 서로 다를 수 있다.

원인 분석:

- 데이터 매칭 문제는 아니다. 앱 데이터에는 추미애 후보의 `huboId`, 이름, 공보 URL이 정상 연결되어 있다.
- 선관위 CDN은 해당 PDF를 `application/x-pdf`로 내려준다.
- PDF 내부에 `SMask`, transparency group, CMYK 이미지, shading 레이어가 포함되어 있다.
- 앱 내부 미리보기는 PDF.js가 PDF를 canvas에 렌더링한다.
- 다운로드 후 확인하는 화면은 브라우저나 OS의 네이티브 PDF 렌더러를 사용한다.
- 따라서 같은 PDF라도 PDF.js와 네이티브 PDF 렌더러의 투명도/마스크 합성 방식 차이로 표시 결과가 달라진다.

현재 대응:

- 문서 프록시는 기본 응답을 `inline`으로 내려주고, 다운로드 버튼은 `attachment` 응답을 사용한다.
- 미리보기 화면 상단에 원본 열기 또는 PDF 다운로드 확인 안내를 표시한다.
- 헤더의 외부 열기 버튼과 PDF 다운로드 버튼을 제공한다.

추가 개선 후보:

- 문제가 있는 PDF만 네이티브 PDF 뷰어로 우회한다.
- 서버 또는 빌드 단계에서 PDF 페이지를 이미지로 변환해 캐싱한다.
- PDF.js 렌더링 옵션 또는 버전 변경으로 해당 파일군의 호환성을 재검증한다.

판단:

- PDF.js만으로 모든 선관위 PDF의 렌더링을 브라우저와 무관하게 보장하기는 어렵다.
- 가장 안정적인 장기 대응은 서버 측 이미지 변환 및 캐싱이다.
